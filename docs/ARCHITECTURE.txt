DOOM PROJECT ARCHITECTURE OVERVIEW
====================================

MAIN MENU (Main.cs)
- Animated background with crossfade
- Glowing "DOOM" title
- Start/Quit buttons
- Last run score display

CORE GAME LOOP (Game.cs)
- 60 FPS game loop (Update → Render → Display)
- Game state management (playing/gameover/win)
- High score persistence
- System coordination

PLAYER SYSTEM (Player.cs)
- Input: WASD/arrow keys + mouse look
- Movement: Collision detection with wall sliding
- Shooting: Shotgun with 7 pellet spread, animation, cooldown
- Health: Damage system with blood flash

ENEMY AI (EnemyAI.cs)
- State machine: idle/walk/attack/pain/death/cooldown
- Multiple enemy types (soldier, caco, soul, cyber)
- Pathfinding and line-of-sight detection
- Wave system with increasing difficulty
- Score tracking on enemy death

RENDERER (Renderer.cs)
- Raycasting engine (core 3D rendering)
- Sprite drawing with occlusion
- Floor/ceiling rendering
- Texture mapping and shading

HUD SYSTEM (Hud.cs)
- Health and ammo displays
- Minimap toggle (M key)
- Crosshair
- Weapon animation display
- Help screen
- Blood flash effect

AUDIO SYSTEM (Audio.cs)
- Background music looping
- Sound effects (shooting, hits, etc.)
- Simple WAV playback

DATA STRUCTURES (Data.cs)
- Enemy, EnemyType, PickupItem classes
- SpriteFrame and WallTexture definitions

LOADER (Loader.cs)
- Resource loading (map, textures, sprites, sounds)
- Image processing and pixel extraction
- Fallback generation for missing assets
