💡 QUICK REFERENCE FOR COMMON QUESTIONS:

"How does the raycasting work?"
→ Renderer.cs: For each screen column, cast a ray from player position, check map for wall hit, calculate distance, draw wall slice scaled by distance.

"How does movement work without getting stuck?"
→ Player.cs: Step() function checks X and Y axes separately, allowing sliding along walls.

"How do enemies know when to attack?"
→ EnemyAI.cs: UpdateEnemies() uses state machine + line-of-sight checks (CanSeePoint).

"How does the shotgun spread work?"
→ Player.cs: FireShotgun() creates 7 pellets with slight random angle variation.

"How is the high score saved?"
→ Game.cs: LoadHighScore()/SaveHighScore() read/write "highscore.txt" as "score,wave".

"What happens when you die?"
→ Player.cs: Damage() sets gameState to "gameover", shows death screen, saves score.

"How does the wave system work?"
→ EnemyAI.cs: CheckWave() spawns next wave when all enemies are dead, increasing difficulty each wave.
